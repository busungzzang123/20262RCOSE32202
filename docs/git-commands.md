# Git 명령어 정리

| 명령어 | 설명 |
| --- | --- |
| `git clone <url>` | 원격 저장소를 내 컴퓨터로 복사 |
| `git status` | 현재 변경 상태 확인 |
| `git add <파일>` | 변경사항을 커밋 대상에 추가 |
| `git commit -m "메시지"` | 변경사항을 커밋으로 저장 |
| `git push` | 내 커밋을 GitHub에 업로드 |
| `git pull` | GitHub의 변경사항을 가져오기 |
| `git log --oneline` | 커밋 기록을 한 줄씩 보기 |
